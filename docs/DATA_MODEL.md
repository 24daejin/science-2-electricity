## Apps Script가 자동으로 만드는 탭

최초 호출 시 헤더와 함께 자동 생성됩니다(`SheetUtils_ensureSheet`). 수동으로 만들 필요 없습니다.

### 진단평가_응답
`제출시각, 학번, 이름, 문항ID, 선택한 보기, 확신도, 정오답`

### 형성평가_응답
`제출시각, 학번, 이름, 소단원ID, 문항ID, 선택한 보기, 확신도, 정오답, 핵심개념`

### 챗봇_로그
`세션ID, 턴번호, 발화자(학생/챗봇/시스템), 메시지, 개념, 학번, 이름, 시각`

### 이탈_로그
`시각, 학번, 이름, 화면, 이벤트(hidden/visible), 비고`

### 세션_상태
`소단원ID, 현재문항ID, 진행상태(대기/진행중/종료), 수정시각, 수정자`

교사가 이 탭의 "현재문항ID"·"진행상태" 셀을 직접 수정하면, 학생 화면이 2~3초 폴링으로 이를 감지해 자동으로 진행됩니다(멘티미터 방식). 예: 소단원1 진행 시 `소단원ID=1, 현재문항ID=F1-03, 진행상태=진행중`으로 바꾸면 학생들은 F1-03 문항을 보게 됩니다. 수업을 마치면 `진행상태=종료`로 바꿔주세요.

## 확신도 태그 → 피드백 매핑

학생이 고르는 확신도 태그는 3종이지만, 시트의 피드백 컬럼은 (정답 여부 × 확신) 2×2 = 4종입니다. 다음과 같이 매핑됩니다(`frontend/assets/js/confidence.js`):

| 확신도 태그 | 버킷 |
|---|---|
| 정확하게 알고 있음 | 확신 |
| 다른 것들이 아니라서 | 비확신 |
| 정확하게는 잘 모르겠음 | 비확신 |

"다른 것들이 아니라서"(소거법)는 개념 이해에 기반한 진짜 확신이 아니라고 보아 비확신으로 분류합니다.

## 로그인 신원 확인의 한계

학번+이름은 학생명단과 대조하지만, 반 코드는 같은 반 전체가 공유하는 값입니다. 즉 같은 반 학생이 다른 학생의 학번·이름을 알고 있다면 그 학생인 척 로그인할 수 있습니다. 교실 내 활동이라는 맥락에서 감수 가능한 트레이드오프로 채택했으며, 더 엄격한 신원 확인이 필요해지면 (a) 학생별 고유 코드로 전환하거나 (b) [docs/OAUTH_SETUP.md](OAUTH_SETUP.md)의 절차로 Google 계정 기반 로그인(GIS)으로 전환할 수 있습니다.
