반별 로그인 코드

학생은 반+번호+이름+이 코드로 로그인합니다. 코드를 바꾸면 즉시 반영되니, 수업 시작 시 칠판에 적어 안내하세요.

소단원별 추가 자료(웹앱·링크)

교과서 활동을 웹앱으로 만들거나 참고 링크가 생기면 여기서 등록하세요. 등록하면 학생·교사 홈 화면의 해당 소단원 카드 안에 버튼으로 바로 나타납니다(코드 수정 불필요).
